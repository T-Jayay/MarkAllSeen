# Mark All Seen

Adds a **Mark all as seen** button to the mod settings that clears every "New!" marker on your profile in one click: logbook entries, items, skills, skins and survivors.

Only things currently showing as new are marked, so anything you unlock later still gets its "New!" marker as normal.

## How to use
Settings → Mod Options → **MarkAllSeen** → **Mark all**. A popup confirms how many entries were marked.

Requires [Risk of Options](https://thunderstore.io/package/Rune580/Risk_Of_Options/). Client-side only; nobody else in your lobby needs it.
